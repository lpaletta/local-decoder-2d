# Code for "Lightweight local decoder for the toric code via binary signal exchange"

This repository presents the code used for the numerical simulations in the paper "Lightweight local decoder for the toric code via binary signal exchange". The code is organized into the five foolowing folders.

1. [convergence] Analysis of the convergence speed of the normalized jump rate to the logical error rate - Fig.6 (b-c)
2. [logical] Analysis of the logical error rate - Fig.5 (a-b)
3. [threshold] Analysis of the threshold - Fig.5 (c)
4. [poisson] Verification that the logical failure behavior is Markovian Fig - Fig.6 (a)
5. [visualization] Space-time representation of the automaton - Fig.4 (b)

Each folder includes a README.md file with more detailed information about the simulation performed for the corresponding figure.
